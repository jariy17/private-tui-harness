# Bundled terminal font

The screenshot renderer bundles the four DejaVu Sans Mono 2.37 faces used for
regular, bold, oblique, and bold-oblique terminal text.

- Source: https://dejavu-fonts.github.io/
- TTF files: used by Resvg for deterministic PNG rasterization
- WOFF2 files: generated from the same TTF files for self-contained SVG output
